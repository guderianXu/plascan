# Dino 完整支持单元等值面连续性优化计划

## 进入依据

采集缺口报告对 Dino 最终 16,096 条开放边完成唯一归因：9,833 条主归因为 support 门，6,263 条位于
8 个角点全部受支持的 TSDF 单元，属于等值面提取或后处理。缺失角点根因进一步表明只有 188 条明确需要
补拍，而 6,263 条后端边界无需增加或插值观测即可处理。

本阶段优先处理这 6,263 条已有完整支持的边界，因为它们比跨阶段投影并重跑 dense matching 风险更低，
也能避免把提取器裂缝误当成影像匹配缺失。

## 目标与约束

目标是在不修改深度图、TSDF、weight 或 support 的前提下，对完整支持零交叉单元使用全局一致的面歧义判定，
减少提取阶段产生的裂边，并保持正常的组件过滤、拓扑清理与 QEM。

- 不启用插值、视觉外壳、占据补全、网格封洞或新增无观测三角面。
- 不以体素聚类或低于 79,500 面的过度简化换取边界下降。
- 只改变同一已观测 TSDF 场的零等值面连接方式；顶点仍位于原零交叉边上。
- 任一召回、轮廓、组件或非流形门退化时回退到当前提取器。

## 实现步骤

### 1. 冻结基线与提取器对照

使用 acquisition report 同一 Dino 输入，分别运行当前提取器和现有 consistent iso-surface 提取器，记录原始面、
组件过滤、拓扑清理、QEM 后边界，以及完整支持边界归因。诊断必须保持 TSDF/support 哈希一致。

### 2. 完整支持单元的一致连接

若现有 consistent 提取器有效，则把它接入严格禁用插值的环拍高质量配置，但仍由独立显式开关控制。若现有实现
同时改变部分支持单元，则增加混合路径：完整支持单元采用全局 face key 的一致判定，部分支持单元继续使用当前
支持蒙版提取规则，避免在观测缺口边界跨接表面。

### 3. 后处理来源保护

为提取器输出记录“完整支持单元生成”的面/边标记。组件过滤与 QEM 不得新增边界；若某阶段边界增加，报告该
阶段和数量并拒绝候选。已有 6,263 条后端边界应在原始或组件过滤阶段下降，不能只在最终 QEM 后改善。

### 4. 测试

- 相邻歧义单元共享同一面连接，互补符号配置不会在公共面产生裂缝。
- 完整支持球面保持闭合；部分支持带仍保持开放，不跨 support 门补面。
- 输入 TSDF 和 support 位级不变，重复运行面索引顺序确定。
- 开关关闭输出与基线哈希一致；失败回退不留下部分候选。

## Dino 验收门槛

- 原始、组件过滤、拓扑清理后的开放边都不高于基线，最终从 16,096 降到 14,000 以下。
- 完整支持单元归因边从 6,263 至少下降 25%，`unclassified=0`。
- 最终 79,500–80,500 面、单组件、0 非流形。
- 深度召回中位/P10/最低不低于 0.9524/0.9244/0.9052。
- 覆盖率不低于 0.9644、IoU 不低于 0.9392、边缘 P90 不高于 17.05 px、SSIM 不低于 0.6754。
- TSDF/support 哈希不变，严格模型继续排除 `anchored_interpolation`。

## 退出条件

若一致提取器无法降低完整支持单元边界，或降低边界但损伤召回/轮廓，则不继续改写等值面规则。下一阶段按
采集缺口报告的前三风险方位，把 9,645 条可重算边界反投影为逐帧 ROI，执行冻结输入的定向多基线局部匹配。

## Dino 对照结果与复盘

现有 consistent iso-surface 提取器已用同一 16 帧、192 TSDF、80k 面、严格禁用插值配置完成对照：

- 原始提取 407,184 面，组件过滤后边界从基线 17,759 降到 153，拓扑清理后从 18,206 降到 153，
  最终网格为 79,999 面、105 条开放边、单组件、0 非流形。边界相对基线减少 15,991 条（99.35%）。
- 深度召回中位/P10/最低为 0.9520268/0.9229391/0.9005576，低于冻结门槛
  0.9524/0.9244/0.9052；因此不能把边界下降直接作为生产优化接受。
- 额外尝试了两轮保拓扑多视深度细化，拓扑和 105 条边界保持不变，但召回进一步降到
  0.9517818/0.9226146/0.8996283。该实验代码已撤回，没有进入生产提交。

结论：一致连接证明大多数开放边确实来自旧提取器的单元连接，但当前实现把 unsupported 样本视为统一外侧值，
会移动 support 边界附近的表面并损伤召回。本阶段未通过全部验收门，现有 consistent 提取器继续保持显式关闭，
不以 105 条边界的视觉改善覆盖质量退化。按退出条件，下一阶段转向把 9,645 条可重算边界反投影为逐帧 ROI。
