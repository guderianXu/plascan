# Dino 多源定向深度恢复计划

## 背景与基线

本阶段只改善有影像测量依据的深度，不启用插值、视觉外壳或网格补洞。

Revision 18 已将融合前低置信深度从统一硬删除改为几何证据门控保留。Dino 16 帧重放结果为：

- 严格禁用插值时的缺失像素从 137,381 降到 134,810，缺失率从 7.686% 降到 7.543%。
- 实测来源像素增加 2,571；融合前有 5,341 个低置信候选通过几何门保留。
- 当前定向 PatchMatch 请求 38,139 个缺口，产生 34,216 个候选，但只有 5,507 个通过；28,708 个
  （83.9%）因单一最近邻深度先验不一致被拒绝。
- 严格禁用插值模型仍有 12,648 条开放边；16 视角验收的轮廓/结构边缘 P90 中位数为
  20.16 px，质量门失败，大洞仍然存在。

当前定向恢复只使用排序最前的两个来源，所有候选共用从最近有效像素复制得到的单值深度先验。
在 Dino 的曲面、遮挡边界和大面积低纹理区域，这个先验容易跨越不同表面层，既错杀真实候选，也无法用
独立来源确认候选是否可靠。

## 目标

把定向恢复改为两个互不重叠来源组产生的独立深度假设。只有两个来源组在逆深度域一致时，才允许候选使用
放宽的曲面先验门；单组候选继续使用现有严格门。最终写入的仍是 PatchMatch 实测深度，并保留
`targeted_patchmatch` 来源码，不能标记为插值。

## 实现步骤

### 1. 独立多源假设与纯函数合并器

在 `DepthGapTargetedRecovery` 中新增多假设合并接口和统计：

- 输入两个或更多候选深度/置信图，每个候选来自不重叠的来源组。
- 逐像素收集有效假设，以逆深度相对离散度不超过 2.5% 作为独立一致门。
- 两个一致假设均达到置信度下限时，使用置信度加权逆深度生成结果。
- 多源一致候选允许相对单值先验最大偏差从 18% 放宽到 35%；没有独立一致证据时仍使用 18%。
- 输出候选数、独立一致数、来源不足拒绝数、假设离散拒绝数、置信度拒绝数和先验拒绝数。

先为以下行为补单元测试：一致曲面候选可恢复、来源组冲突时拒绝、极低置信拒绝、越过放宽先验仍拒绝、
仅有一个来源组时保持旧行为。

### 2. 互补来源分组与受限 PatchMatch

在 `DepthMapGenerator` 的轨道物体定向恢复阶段：

- 从已经通过 pair 几何验证并按质量排序的来源中最多取 6 个。
- 按排序奇偶交错为两个互不重叠的 3 视图组，使每组都包含近邻和相对更宽基线来源。
- 每组只在同一个缺口估计蒙版内运行受先验约束的 PatchMatch，不增加全图计算。
- 少于 4 个来源时回退当前单组流程，不伪造独立一致证据。
- 任一候选组失败时记录原因；只有剩余证据满足旧门时才允许恢复。

预计计算量最多增加一次局部 PatchMatch，显存仍由现有 CUDA 自适应重试和取消机制管理。

### 3. 来源、缓存与诊断闭环

- 将来源组数、每组来源数、一致假设数和各拒绝原因写入 manifest/CLI 报告。
- 新参数进入 MVS 配置哈希；算法修订递增，旧工作区不得误复用。
- 多源恢复像素继续写入 `targetedGapRecoveredMask` 和 `DepthProvenance::TargetedPatchMatch`。
- 后续跨视一致性、低置信几何门和最终缺失原因统计保持不变，作为第二道安全门。

### 4. 验证与 Dino A/B

本地验证：

```powershell
cmake --build build/windows-vcpkg-cuda-release --target test_mvs_depth_gap_targeted_recovery test_mvs_pipeline test_mvs_workspace_manifest mvs_depth_reprocess_cli -j 12
```

运行相关测试程序，并由 GitHub Actions 验证 Linux/GCC。然后使用与 Revision 18 相同的 Dino 输入、
`highest + orbital_object + mild + CUDA` 参数重放，生成 192 分辨率、80k 目标面、禁用插值模型和 16 视角
质量报告。

## 验收门槛

进入后续优化前，本阶段至少满足：

- 新增实测来源像素相对 Revision 18 增加，且严格无插值缺失率低于 7.543%。
- 定向恢复后最终存活像素增加，不能只提高初始候选而在跨视一致性阶段全部被删除。
- 模型中位/P10/最低深度召回率不得低于 Revision 18 的 0.9519 / 0.9241 / 0.8963。
- 模型组件数保持 1，非流形边不增加；开放边目标低于 12,000。
- 16 视角中位 IoU 不低于 0.9358，不能以轮廓膨胀换取表面覆盖。

如果实测像素增加但开放边仍高于 12,000，下一步转向“一致性后残余缺口重估”：用全部已完成深度帧构造
可见性分层先验，再对残余缺口局部重跑，而不是继续放宽单帧先验或启用无依据插值。

## 回退与风险控制

- 所有新逻辑由配置开关控制；关闭后恢复 Revision 18 行为。
- 独立来源组必须不重叠，避免同一错误匹配被重复计票。
- 多源冲突、低置信、无界先验和蒙版外像素一律不写入。
- 不修改相机、不覆盖现有 Dino 工作区；每次验收使用新的独立输出目录。
- 如果 GPU 局部重跑失败，记录失败并回退单组严格门，不静默改用插值。
