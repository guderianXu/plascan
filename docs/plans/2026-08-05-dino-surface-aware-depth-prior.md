# Dino 多锚点曲面深度先验计划

## 进入本阶段的原因

Revision 19 已证明独立多源假设有效：Dino 有 25,548 个缺口像素得到两个不重叠来源组的一致深度，
但最终只恢复 6,720 个。剩余拒绝中，20,737 个仍未通过从“最近一个有效像素”复制而来的单值先验门。

Revision 19 相对 Revision 18 的严格无插值结果已有正向改善：

- 缺失率 7.543% → 7.511%。
- 模型深度召回率（中位/P10/最低）0.9519 / 0.9241 / 0.8963 →
  0.9529 / 0.9249 / 0.9013。
- 16 视角中位 IoU 0.9358 → 0.9382，覆盖率 0.9597 → 0.9627，边缘 P90
  20.16 px → 17.62 px。

但严格禁用插值模型仍有 15,814 条开放边，大洞没有消失。下一步不能继续无条件放宽先验，而要把单锚点
先验升级为有几何安全门的多锚点曲面先验。

## 目标与非目标

目标是在大面积平滑曲面或连续斜面缺口内，为局部 PatchMatch 提供更接近真实表面的逆深度中心和搜索半径，
减少正确多源候选被错误先验拒绝的数量。

本阶段不做以下操作：

- 不启用图像内插值、网格补洞、视觉外壳或轮廓挤出。
- 不在只有单侧锚点的轮廓边界外推曲面。
- 不跨越明显深度分层或强图像边缘传播先验。
- 不修改相机或覆盖已有 MVS 工作区。

## 实现步骤

### 1. 四方向多锚点采样

在 `DepthGapTargetedRecovery` 中为每个缺口像素沿左、右、上、下搜索最近有效深度锚点：

- 每个方向最大搜索距离受现有 `maximumPriorDistancePixels` 限制。
- 只在支持蒙版内部搜索；越过蒙版外区域后该方向无效。
- 至少需要三个方向锚点，其中必须包含一组水平或垂直对向锚点，才允许构造曲面先验。
- 只有单侧或两个同侧锚点时回退 Revision 19 的最近邻先验。

### 2. 稳健逆深度平面

对通过方向门的锚点拟合 `inverse_depth = a*x + b*y + c`：

- 使用距离倒数作为权重求解 3 参数加权最小二乘。
- 锚点逆深度相对离散度超过 12% 时视为跨层，不使用曲面模型。
- 拟合残差超过 2.5% 或矩阵病态时回退最近邻先验。
- 预测值必须为有限正数，并限制在锚点深度包络外最多 8%，防止大幅外推。
- 曲面先验的搜索半径综合拟合残差、锚点距离和 Revision 19 的 35% 上限；锚点越远或残差越大，
  置信门越严格，而不是无限放宽。

输出逐像素 `priorSupportCount` 和 `priorResidual`，用于统计与后续候选门控。

### 3. 与多源假设合并

- 两个独立来源组一致时，优先与通过安全门的曲面先验比较。
- 曲面先验不可用时保持 Revision 19 的最近邻先验和 18%/35% 两级门。
- 单组候选不得借用曲面先验放宽门，必须保持 18% 严格门。
- 恢复像素仍标记为 `targeted_patchmatch`；曲面先验本身不写入最终深度，因此不属于插值来源。

### 4. 诊断、缓存和测试

新增统计：曲面先验覆盖像素、方向不足、锚点跨层、拟合失败、残差超限、曲面先验接受候选和回退次数。
参数进入配置哈希并递增算法修订。

单元测试覆盖：

- 平滑斜面内部矩形缺口能恢复正确逆深度趋势。
- 深度台阶两侧锚点离散过大时拒绝曲面先验。
- 轮廓单侧锚点不外推。
- 多源一致候选可通过曲面先验，冲突候选仍拒绝。
- 关闭开关时保持 Revision 19 行为。

## 验证与验收门槛

先完成 MSVC 相关构建和测试，再由 GitHub Actions 验证 Linux/GCC。Dino 使用与前两阶段完全相同的
`highest + orbital_object + mild + CUDA` 输入，重新生成 192 TSDF、80k 目标面、严格禁用插值模型和
16 视角报告。

相对 Revision 19 至少满足：

- 最终严格无插值实测像素继续增加，缺失率低于 7.511%。
- 中位/P10/最低召回率不得低于 0.9529 / 0.9249 / 0.9013。
- 中位 IoU 不低于 0.9382，边缘 P90 低于 17.62 px。
- 模型保持单组件、零新增非流形边；开放边必须低于 15,814，目标低于 14,000。
- 曲面先验接受的候选在后续跨视一致性后必须有净存活，不能只增加临时候选。

如果曲面先验仍无法把开放边降到 14,000 以下，下一阶段改为一致性后残余缺口重估：利用所有已完成深度帧
建立可见性分层先验，再仅对最终残余缺口局部重跑。该阶段也必须先单独写计划，不能通过继续放宽当前门限替代。

## 回退

- 新逻辑由配置开关控制，关闭后完全回退 Revision 19 最近邻先验；Dino 验收未达到净收益后，生产默认值
  保持关闭，仅保留为实验能力。
- 任一方向、拟合、包络或残差安全门失败都回退最近邻先验，不中止整帧。
- GPU/CUDA 行为不变；曲面先验只在 CPU 生成小型提示图，不增加新的长期缓存。

## 实施与 Dino 验收结果

Revision 20 已实现四方向锚点、加权逆深度平面、安全包络、残差门、统计和配置哈希。为避免单组来源
意外借用曲面先验，目标同时保留最近邻提示；只有两个独立来源组形成共识时才允许曲面先验参与最终门控。
MSVC 定向恢复、MVS 流水线、工作区和工作流配置共 114 项测试通过。

Dino 使用与 Revision 19 相同输入重放，曲面先验覆盖 11,917 个缺口像素并接受 1,854 个多源候选，
但没有形成净深度增益：

- 定向恢复总数 6,720 → 6,534，最终实测像素 1,653,079 → 1,652,962。
- 严格无插值缺失 134,251 → 134,368，缺失率 7.511% → 7.518%。
- 召回率（中位/P10/最低）0.9529 / 0.9249 / 0.9013 → 0.9527 / 0.9245 / 0.9021。
- 开放边 15,814 → 15,797；中位边缘 P90 17.62 px → 17.42 px，SSIM 0.6754 → 0.6763。
- 中位覆盖率 0.9627 → 0.9626，IoU 0.9382 → 0.9379，质量门仍失败；联系表仍显示腹部和遮挡侧的
  大面积贯穿空洞。

因此本阶段判定为“局部轮廓略有改善，但未通过严格完整性验收”。曲面先验改为默认关闭，不把回归带入
常规流程。下一阶段按约定先制定一致性后残余缺口局部重估计划，再开始实现。
