# Dino 深度来源与插值策略验收（2026-08-05）

## 目标

验证 MVS 算法修订 17 的三项生产契约：

1. 每个最终有效深度像素恰好具有一种来源；
2. “禁用插值”只拒绝锚定插值，不误删定向 PatchMatch 或跨视测量恢复；
3. 在同一深度批次与同一网格参数下，量化允许插值对开放边和深度召回率的影响。

## 输入与配置

- 数据：Dino 环拍 16 张影像，56 个已验证像对；
- 深度：`highest`、`orbital_object`、`mild`，请求 8 源，场景策略实际使用最多 6 源；
- 模型：`depth_tsdf`，分辨率 192，目标 80,000 面，不计算顶点色；
- 对照变量：仅 `interpolation=disabled/enabled`；
- Windows/MSVC/CUDA 重放总耗时：48.724 秒。

工作区路径不写入仓库。可在本机以变量替换后运行：

```powershell
$replayReport = '<mvs-output>/mvs_replay_report.json'
python scripts/validation/summarize_mvs_depth_provenance.py $replayReport `
  --output '<mvs-output>/depth_provenance_validation.json'
```

## 深度来源结果

16 个最终深度帧均存在无损 `depth_provenance_path`，验证器返回通过：

| 来源 | 像素数 | 最终有效深度占比 |
|---|---:|---:|
| 原生 PatchMatch | 1,607,554 | 94.5544% |
| 定向 PatchMatch | 1,380 | 0.0812% |
| 跨视测量恢复 | 38,217 | 2.2479% |
| 锚定插值 | 52,985 | 3.1165% |
| 合计 | 1,700,136 | 100.0000% |

未分类有效像素为 0。前三类有影像测量证据的深度合计 1,647,151 像素，占 96.8835%。蒙版支持区
缺失 87,194 / 1,787,330 像素，缺失率 4.8784%。定向恢复请求 38,139 像素，产生 34,216 个
候选并在一致性前接受 5,507 个；最终来源图中仍归为定向 PatchMatch 的像素为 1,380，其余候选在
后续一致性、跨视测量更新或后处理中被重新分类/剔除。

## 模型 A/B

| 指标 | 禁用插值 | 允许插值 | 变化 |
|---|---:|---:|---:|
| 顶点 | 42,119 | 41,094 | -1,025 |
| 面 | 79,998 | 80,000 | +2 |
| 连通分量 | 1 | 1 | 0 |
| 开放边 | 16,000 | 6,560 | -9,440（-59.0%） |
| 深度召回率中位数 | 95.23% | 95.33% | +0.10 个百分点 |
| 深度召回率 P10 | 92.68% | 91.89% | -0.79 个百分点 |
| 最低帧召回率 | 90.08% | 89.80% | -0.28 个百分点 |

禁用插值时，TSDF 统计确认 `effective_exclude_anchored_interpolation_observations=true`，共拒绝
1,382,287 次落在锚定插值像素上的投影采样；输出仍为单连通分量且深度完整性门通过。允许插值将
开放边减少 59.0%，但并未改善尾部视角召回率。视觉外壳候选因 56 个分量、最大分量仅 38.8% 而被
安全门拒绝，因此该对照的开放边改善来自深度插值参与 TSDF，而不是无证据闭壳。

## 结论

修订 17 已把“测量恢复”和“几何插值”从同一个修复掩模拆开。用户禁用插值时，系统保留 96.88%
有测量来源的有效深度并给出更保守的开放表面；允许插值时，开放边明显减少，但不会被表述为新增的
实测匹配。Dino 剩余空缺主要仍受原始影像纹理、遮挡与视角覆盖限制，不应通过无门控外推强行闭合。
