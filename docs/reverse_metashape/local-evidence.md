# Local reverse-engineering evidence

The Metashape case packages referenced by these reports are retained locally
under `work/`. They include scope records, timelines, hashes, string tables and
Ghidra decompiler output used to audit the findings.

Raw case packages are intentionally excluded from this public repository because
they contain third-party proprietary binary-derived material. The publishable,
clean-room conclusions, parameter mappings, implementation notes and public
references are maintained in this directory. Evidence identifiers and local
paths remain in the reports so an authorized analyst with the original case
package can reproduce the trace.
