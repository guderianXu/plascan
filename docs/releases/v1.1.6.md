# PlaScan v1.1.6

发布日期：2026-06-21

## 新增

- 当前发布目标同步到 `v1.1.6`，包括根项目版本、core 项目版本、`CHANGELOG.md`、本 Release 文档和 repo hygiene 版本一致性测试。
- SfM 匹配链路新增 guided matching v1 诊断字段，记录候选 pair 来源、优先级、guided eligibility、epipolar band、pending/failed/skipped 原因和后续 rematching 入口信息。
- 多视 track 增加置信度和来源统计，BA observation 可综合 track length、feature scale、feature score、matcher/source confidence 做质量感知权重。
- MVS depth manifest 增加 `source_view_count`、`mean_source_quality_score`、`min_source_quality_score`、`mean_depth_confidence` 和 `valid_pixel_count`，让 GUI 和报告窗口直接消费 metadata。
- GUI 特征点可视化与特征提取 runner 改为通用命名，新增 `FeaturePointVisualizationDialog` / `FeatureExtractionRunner`，移除旧 `SuperPoint*` / `SuperGlue*` GUI 接口。

## 优化

- SfM 报告更清晰地区分候选图、实际匹配图、几何验证图、guided rematching 资格和 BA 输入质量，方便定位无人机航测数据注册率低、匹配对质量差或 track 质量不足的问题。
- MVS source planning 把 shared tracks、几何内点、基线和重叠质量汇总成 source quality score，并写入 depth artifact 与 workspace manifest。
- MVS 深度图记录现在携带 source/confidence 摘要，目录树和 GUI 状态不再依赖只扫描输出目录来猜测主状态。
- 网格/密集点云相关流程继续向流式、分块和可诊断方向收敛，便于处理大 PLY、密集点云到 mesh 和地形网络阶段的内存峰值问题。
- Windows CUDA 构建说明继续固定到 `E:\code\plascan\build\windows-vcpkg-cuda-release`、CUDA 13.1 和 `libtorch-cu130`，减少旧 CPU LibTorch 或旧 build cache 干扰。

## 修复

- 修正 Windows 上 `DenseMatchIntegrationTest.SaveAndReloadDisparity` 使用硬编码 `/tmp/test_disparity.tif`，导致没有 `/tmp` 目录时 `cv::imwrite` 保存失败的问题；现在使用系统临时目录。
- 修正 MVS depth artifact 后续更新可能覆盖已有非空 `source_plan` 的问题，filtered depth 写回时会保留原始选源依据。
- 修正旧 `SuperPointRunner`、`SuperGlueRunner` 和 `SuperPointVisualizationDialog` 命名残留造成的 GUI 接口误导，保留算法能力但移除旧的专有 GUI 名称。
- 修正部分匹配查看、影像加载和密集点云/模型 metadata 刷新路径中状态提示不够明确的问题，失败时更容易定位到图像路径、PLY 规模或运行时依赖。
