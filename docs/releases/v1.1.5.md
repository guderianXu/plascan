# PlaScan v1.1.5

发布日期：2026-06-19

## 新增

- 当前开发和发版目标统一同步为 `v1.1.5`，包括：
  - 根目录 `CMakeLists.txt`
  - `src/core/CMakeLists.txt`
  - `CHANGELOG.md`
  - `docs/releases/v1.1.5.md`
  - 版本一致性测试
- 新增四阶段重建链路优化计划：
  - 阶段一：MVS workspace、取消、内存预算和 GUI metadata 刷新。
  - 阶段二：MVS source planning、深度图质量、confidence/valid mask 和融合鲁棒性。
  - 阶段三：DEM/DOM 正式产品链、质量栅格、mosaic 和 terrain manifest。
  - 阶段四：DEM/LiDAR 后验验证、点云/DEM 配准、误差报告和 BA soft prior。
- 新增发版说明约束：推送 tag 后必须创建或更新同名 GitHub Release，正文必须包含新增、优化、修复、验证和已知问题，不能只写版本号。
- 参考 DEM soft prior 已接入 BA 执行链路，预检通过后可从 GUI 启动参考地形平差，并把关联统计和约束参数写入 BA 报告。
- 参考地形平差 GUI 入口现在可在没有 DEM、但存在 role=ba_prior 的 PLY LiDAR/点云时，显式启动 LiDAR 点到面 BA soft prior。
- 参考数据精度检查新增可追溯 artifact：
  - DEM 差分 GeoTIFF。
  - DEM 绝对差分 GeoTIFF。
  - 点云配准前误差 CSV。
  - 点云配准后误差 CSV。
- 点云 Sim3 transform JSON。
- 参考点云精度检查支持非配对点云。重建点云和 LiDAR/参考点云点数不一致时，会自动使用最近邻平移配准生成误差统计与 artifact。
- 新增 `src/core/mvs/README.md` 和 `src/core/terrain/README.md`，分别说明 MVS manifest/source planning/streaming fusion 与 DEM/DOM quality product chain。
- `reconstruct_pipeline_cli` 新增 `--mvs-depth-only`，可只生成 MVS depth/raw/confidence/mask/manifest 并在融合、网格和 terrain 前停止，方便大航测数据做显存、取消、恢复和 source plan 验证。
- `README.md` 增加 Windows CUDA 固定构建入口、`libtorch-cu130` 运行时说明和四阶段重建链路状态摘要。

## 优化

- `v1.1.5` Release 正文优先从本文件或同步内容生成，确保 GitHub Release 页面可以直接看懂本版本更新内容。
- `docs/PROJECT_ARCHITECTURE.md` 已同步 MVS workspace manifest、MVS source planner、terrain product manifest、DEM mosaic、QC report 和 ReferenceTerrainPrior。
- 参考地形 BA 约束使用 sigma、最大关联距离、Huber delta 和 track 关联统计进行诊断，避免把 DEM 高程作为不可解释的硬约束。
- 参考 DEM/LiDAR 质量报告的项目记录会写入配套 artifact 的绝对路径，后续 GUI 报告窗口和目录树可以直接消费 metadata。
- 点云质量报告新增 `cloud_alignment_method` 字段，区分 `paired_similarity` 和 `nearest_neighbor_translation`。
- 深度图融合取消语义更干净：每次新融合开始会清空上一轮 fused points 和 filtered depth cache，取消或失败后不会把 stale 输出暴露给调用方。
- 稠密点云 GUI 补齐高级 MVS 控制项：最小一致视图数、几何一致性过滤、最大重投影误差、孤立噪点面积阈值和融合最长边。默认值保持为现有配置默认，只有用户显式修改时才改变 MVS 行为。
- 四阶段计划的推荐里程碑统一改为：
  - `v1.1.5-alpha.1`：阶段一完成并通过 aerial GCP smoke 验证。
  - `v1.1.5-alpha.2`：阶段二完成，深度质量和 source planning 收敛。
  - `v1.1.5-alpha.3`：阶段三完成，terrain quality products 可用。
  - `v1.1.5`：阶段四验证报告和 BA soft prior 完成，CHANGELOG、Release 文档和 tag 同步。

## 修复

- 修正版本同步检查仍固定到 `v1.1.4` 的问题，repo hygiene 测试改为检查 `v1.1.5`。
- 修正发版流程示例仍使用旧版本号的问题，示例 tag 更新为 `v1.1.5`。
- 修正四阶段计划里 release milestone 仍引用 `v1.1.2` 的问题。
- 修正 SuperPoint 单测只用相对路径查找模型和测试影像，导致仓库根目录或 CTest 工作目录下找不到已存在模型的问题。
- 修正深度图融合在调用方复用输出数组时，取消后可能保留旧点云结果的问题。
- 修正同一 MVS 帧写入过滤后深度产物时，空 `source_plan` 会覆盖初始深度产物已记录 source planning 依据的问题；manifest 更新现在会保留已有非空 `source_plan`。
- 修正 SfM 稀疏点云导出颜色采样在完整航测数据上按点反复读大图、或长期缓存过多彩色图像的问题；现在先按影像分组收集采样请求，每张影像只加载一次并批量填充点云颜色。
