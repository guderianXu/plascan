# PlaScan v1.1.0-alpha.3

发布日期：2026-06-15

## 优化

- GUI 影像切换改为后台加载并忽略过期结果，减少大图和特征覆盖层加载时的界面停顿。
- 特征点覆盖层在大规模点集下使用批量图元绘制，默认特征点颜色改为蓝色，降低场景图元数量和刷新成本。
- 空三前置检查复用生成的匹配 pair plan，并通过匹配图覆盖率和连通性判断上游数据是否完整。
- 已知相机 SFM 配对流程在大规模数据上保持有界候选，避免把 444 张影像退化为全连接 N² 匹配。
- SfM/BA 结果增加正式重建与两视图预览的质量元数据，下游流程只消费正式稀疏结果。

## 修复

- 修复 Windows 下保存 `.plascan` 项目时，当前 `PlascanArchive` 的只读 zip 句柄阻塞 libzip 临时文件重命名，导致 `project_files.json` 写入失败的问题。
- 修复空三启动和匹配文件检查路径中的 GUI 线程阻塞风险，任务启动改为队列/后台执行。
- 修复已完成匹配后仍被误报“影像对匹配不完整”的判断逻辑。
- 修复旧式两视图初始三角化结果被误当作正式空三稀疏点云的问题。
