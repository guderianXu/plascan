# PlaScan v1.1.4

发布日期：2026-06-19

## 新增

- `reconstruct_pipeline_cli` 增加 MVS 长链调试参数：
  - `--mvs-res-scale`
  - `--mvs-iterations`
  - `--mvs-confidence`
  - `--mvs-fusion-confidence`
  - `--mvs-gpu-frame-workers`
  - `--mvs-cpu-frame-workers`
  - `--mvs-max-frames`
  - `--mvs-fusion-max-image-dim`
- MVS JSON 报告记录深度图产物、源影像、mask/raw depth/raw confidence、有效像素统计、置信度过滤统计、局部离群过滤统计和融合降采样配置。
- GUI 密集重建结果使用项目 metadata 刷新目录树，深度图和点云按文件名自然排序。
- SfM workflow 报告增加 pair plan、候选图、实际匹配图、连通分量、pending/failed/skipped pair 和注册质量统计。

## 优化

- MVS 融合阶段从全量常驻深度图改为有界流式窗口，默认融合最长边限制为 2048，降低 6000x4000 航测影像的内存峰值。
- 融合阶段对已完成置信度和局部离群过滤的深度图使用快速反投影路径，跳过重复昂贵的窗口内全量 BFS 融合检查。
- 流式融合加入点数阈值预聚合，超过阈值时先按 voxel 聚合到目标点数附近，避免后半程内存继续上涨。
- 下采样 depth/confidence 时同步缩放相机内参，并在颜色缓存中按融合网格尺寸重采样影像，保证融合点颜色不丢失、不错位。
- 深度图保存队列、取消检查和后处理进度继续收敛，减少 GUI 点击取消后长时间停在“正在取消稠密重建”的情况。
- 已知外参 SfM/BA 改为 soft prior 设计，外参默认参与优化但受位置/旋转 sigma、Huber 和权重约束。
- 特征匹配和空三 pair planning 更适合大项目：优先使用文件序列窗口、相机中心邻域和显式重叠对，避免默认 N² 全量匹配。
- LiDAR 约束增加距离/曲率质量权重和更完整的 A-B 诊断工具，便于后续把 DEM/LiDAR 作为 BA 软约束。

## 修复

- 修复深度图估计完成后目录树不显示深度图的问题。
- 修复 MVS 融合阶段重复加载/持有全尺寸 depth/confidence/color 造成长时间运行内存增长的问题。
- 修复融合下采样后颜色采样仍按原图尺寸索引，导致点云颜色可能错位或丢失的问题。
- 修复深度图局部红色孤立噪点缺少过滤统计的问题，报告中记录 confidence/local outlier 移除数量。
- 修复 SfM 诊断中候选匹配、实际匹配和几何验证失败难以分辨的问题。
