# PlaScan v1.1.1

发布日期：2026-06-16

## 优化

- README 删除过时的“实测性能”表，避免把旧设备、旧数据和旧参数下的局部 benchmark 当作当前真实性能承诺。
- README 环境构建说明调整为三层入口：系统依赖已就绪时的直接 CMake 构建、推荐的 vcpkg/CMake preset 构建、以及 `scripts/env/` 生成本机 Python/LibTorch 环境后的构建。
- 平台支持矩阵新增 Windows (NVIDIA)，并明确 Windows 原生 MSVC/Ninja/PowerShell 构建、Linux NVIDIA 构建和 macOS Apple Silicon CPU/MPS 路径的差异。
- GitHub Actions CI 明确为 Linux CPU-only 构建，配置时显式关闭 conda/vcpkg 自动发现，减少 CI 与本机 CUDA 工作站配置互相污染。

## 修复

- 修复 CI Configure 阶段缺少 Qt OpenGLWidgets 开发包的问题；workflow 增加 `libqt6opengl6-dev`。
- 修复 Python 脚本测试在 CI 上缺少 `numpy` 的后续失败风险；workflow 增加 `python3-numpy`。
- 修复 CPU LibTorch 构建下，`SFMService` 无条件包含并调用 CUDA-only `c10::cuda::CUDACachingAllocator` 的兼容风险。现在只有 CMake 检测到 LibTorch CUDA 支持时才启用该清理路径。

GitHub Actions 侧配置：

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_TESTS=ON \
  -DPLASCAN_ENABLE_CONDA=OFF \
  -DPLASCAN_ENABLE_VCPKG=OFF \
  -DTorch_DIR="$PWD/.deps/libtorch/share/cmake/Torch"
```
