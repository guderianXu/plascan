# PlaScan v1.1.0-alpha.4

发布日期：2026-06-15

## 优化

- Metashape 相机转换会保留 adjusted calibration 中的 `k1/k2/k3/p1/p2`，并写入输出 `.tsai`。
- 项目元数据相机只作为增量 SfM/BA 的初值；显式 `.tsai` 文件列表才触发固定已知外参直接三角化。
- 固定已知外参 SfM 增加两视图退化质量门，防止把几乎全由 two-view track 组成的点云发布为正式空三结果。

## 修复

- 修复 Metashape aerial GCP 数据因相机畸变被导出为 0，导致已知位姿三角化点云和无人机轨迹异常的问题。
- 修复 SFM 稀疏结果质量元数据中 BA 状态被无条件标记为已应用的问题。
