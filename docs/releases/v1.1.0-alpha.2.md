# PlaScan v1.1.0-alpha.2

发布日期：2026-06-13

## 新增

- 固定相机 SFM 匹配候选生成支持相机足迹重叠对输入。
- `SFMService` 可基于 `.tsai` 相机、影像尺寸和参考球面自动计算已知相机足迹重叠对。
- 新增 vcpkg/CMake preset 和 `scripts/env/` 环境准备脚本，覆盖 vcpkg、Python、LibTorch 和 CPack 配置。

## 优化

- 对地或大规模已知相机数据优先使用参考球面足迹重叠裁剪匹配对，降低纯中心邻域造成的错误候选。
- SFM 和 GUI 匹配流程对内点不足的影像对做日志采样，只展示前 8 个样例并在结束时汇总总数。
- 相机三维视图根据视口宽度和相机数量动态限制标签数量，减少大批量相机名称重叠。
- Windows/CPack 安装规则和运行时捆绑脚本做了跨平台适配。

## 修复

- 修复已知相机大数据集在初始化稀疏重建时不能优先使用真实重叠关系的问题。
- 修复 3D 相机显示中大量文件名挤成黑块的问题。

构建：

```bash
cmake --build build -j$(nproc)
```

结果：通过。

相关测试：

```bash

./tests/test_gui_project_utils
python -m py_compile scripts/env/configure_with_env.py scripts/env/setup_libtorch.py scripts/env/setup_python_env.py scripts/env/env_common.py scripts/env/setup_vcpkg.py
```

结果：

- SFM 配对和重叠分析相关测试 8/8 通过。
- GUI 工具测试 76/76 通过。
- Python 环境脚本语法检查通过。

数据集验证：

```bash
timeout 240s build/bin/three_d_reconstruction_cli \
  build/benchmark_runs/agisoft_aerial_gcps_ground_best/subset_48.lis \
  --output-dir build/benchmark_runs/agisoft_aerial_gcps_overlap_subset48_sfm_check \
  --device cuda \
  --quality 3 \
  --threads 32 \
  --cuda-parallel-pairs 1 \

  --stop-after-sfm
```

结果：

- 固定相机位姿注册：48/48。
- 稀疏点云：7835 点。
- 平均重投影误差：0.75 px。
