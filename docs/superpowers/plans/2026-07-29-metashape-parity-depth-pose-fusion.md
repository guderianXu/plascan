# 面向 Metashape 效果对齐的位姿、深度与融合优化计划

> 状态：实施中（已完成三场景统一复现，当前优先修复 MVS→TSDF 证据生命周期）
> 日期：2026-07-29
> 首要数据集：Dino、Temple、Hyb2
> 对照实现：Metashape、COLMAP PatchMatch、OpenMVS
> 主构建目录：`E:\code\plascan\build\windows-vcpkg-cuda-release`
> Python：`E:\code\plascan\.venv\Scripts\python.exe`

## 1. 目标

在不依赖无证据大孔填充、不牺牲 Dino 尖刺和 Temple 细柱结构的前提下，缩小 PlaScan 与
Metashape 在环拍小目标模型上的差距。优化重点依次为：

1. 用统一输入和统一评价器分离位姿、深度、TSDF 与网格阶段的责任。
2. 在 TSDF 前用多视深度证据细化局部相机位姿。
3. 让 MVS 保留多假设、逐像素源视图和可追踪的深度证据类别。
4. 把 TSDF 从整帧固定权重改为逐像素不确定度感知融合。
5. 仅在隐式场达到完整性门后进行网格修复、重网格化和简化。
6. 保证 GUI“工作流程 → 生成模型”和 CLI、验证脚本使用同一配置解析与核心实现。

“达到 Metashape 效果”不以单张截图定义，而以逐视角召回、跨视深度残差、开放边、错误内层、
表面粗糙度和三数据集非回归共同验收。

## 3. 非目标和安全边界

- 不全局把 TSDF 最小相机支持降为 1。
- 不把所有插值深度当成原生深度。
- 不用更宽截断带掩盖未经测量的位姿误差。
- 不用无轮廓、无可见性、无多视支持的大孔填充通过质量门。
- 不以纹理覆盖几何空洞。
- 不覆盖 Hyb2、Dino、Temple 已有深度和模型产物；每次 A/B 使用独立输出目录。
- 不在 GUI 中增加第二个模型生成入口。
- 不把第三方库直接变成不可审计的默认黑盒；COLMAP/OpenMVS 先作为归因对照。
- 不修改 `3rdparty/plapoint`、`3rdparty/plamatrix` 子模块状态。

## 4. 总体架构

### 4.1 复用处理基线管理

复用 `src/core/qc/ProcessingBaselineManager`，扩展而不是另建重复基线系统。新增可选记录：

- 输入影像、相机、深度和蒙版指纹。
- 位姿来源与细化前后差异。
- 深度生成器和参数指纹。
- 每类深度证据的像素数量。
- TSDF 配置和实际生效参数。
- 固定视角与逐相机质量指标。
- 参考模型、COLMAP、OpenMVS 对照结果。

基线比较必须先验证输入指纹一致，防止把不同位姿、不同深度或旧 GUI 输出误认为算法回归。

### 4.2 位姿细化

在 `src/core/mvs` 新增 `DepthPoseAlignmentRefiner`，职责限制为：

- 输入相机、深度、置信度、蒙版和邻接关系。
- 固定全局尺度和一个锚定相机。
- 计算点到平面、轮廓重投影、稀疏特征重投影和可选光度残差。
- 对每台相机只求解小范围 SE(3) 增量。
- 输出候选位姿、协方差、优化前后指标和是否接受。

该类不直接修改项目；由 MVS 工作流在质量门通过后选择是否采用并持久化派生位姿。

### 4.3 深度证据分类

在 `MvsTypes` 和 `MvsWorkspaceManifest` 中为最终深度像素定义可持久化类别：

- `measured`：原始 PatchMatch/立体匹配测量。
- `cross_view_validated`：至少两个独立源视角确认。
- `regularized`：由边缘感知正则化恢复，但邻域有测量锚点。
- `interpolated`：小孔或轮廓邻域插值。
- `invalid`：无可用证据。

类别图与连续置信度图同时保存。TSDF 必须同时读取类别和连续权重，不能再仅凭单一 confidence 值
推断来源。

### 4.4 不确定度感知融合

每个深度样本的融合带宽由以下三项组成：

```text
depth_sigma
+ projected_pose_sigma
+ orbital_gap_allowance
```

其中：

- `depth_sigma` 来自多假设离散度和跨视残差。
- `projected_pose_sigma` 来自位姿细化的协方差投影。
- `orbital_gap_allowance` 只在显著角度缺口扇区生效。

证据类别控制写入权限：

| 类别 | 创建新表面 | 增强已有表面 | 自由空间雕刻 |
|---|---|---|---|
| measured | 是 | 是 | 受冲突保护 |
| cross_view_validated | 是 | 是 | 受冲突保护 |
| regularized | 仅有邻域锚点时 | 是 | 否 |
| interpolated | 否 | 是 | 否 |
| invalid | 否 | 否 | 否 |

## 5. 实施阶段

### 阶段 0A：修复深度帧生命周期与证据完整性

在继续位姿、PatchMatch 或 TSDF 参数优化前先完成：

1. 把帧状态拆分为“估计成功”“可作为一致性参考/来源”“最终可融合”。
2. `accepted` 和 `validation_only` 都必须完成跨视一致性、后处理和证据图生成；
   `rejected` 才能提前退出。
3. 最终质量决定必须基于一致性处理后的覆盖、置信度和证据统计。
4. TSDF 只允许加载证据产物完整的提升帧；缺失证据不得静默替换为全零图。
5. manifest 为每帧记录证据完整性和缺失原因。
6. 模型任务失败后不得把旧模型继续标记为本次生成成果。

阶段门：

- 所有被 TSDF 加载的帧都具有几何支持、来源掩码和逆深度离散度。
- Dino 第 13 帧完成一致性处理，不再出现零一致性观测。
- 流式与内存模式对同一输入产生相同的帧级证据集合。
- 新增生命周期、manifest 完整性和旧产物新鲜度测试。

### 阶段 0：四组归因基线

新增 `scripts/validation/run_depth_pose_fusion_ablation.ps1`，对每个数据集运行：

1. PlaScan 位姿 + PlaScan 深度 + PlaScan TSDF。
2. 参考/Metashape 位姿 + PlaScan 深度 + PlaScan TSDF。
3. PlaScan 位姿 + COLMAP/OpenMVS 深度 + PlaScan TSDF。
4. 可导出的 Metashape 深度或参考模型投影 + PlaScan TSDF。

所有组合使用同一网格设置、相同坐标和相同评价器。输出：

- `ablation_manifest.json`
- `depth_metrics.json`
- `pose_metrics.json`
- `fusion_metrics.json`
- Front/Side/Top/四个斜视角 contact sheet
- 每帧深度覆盖、残差、召回和孔洞归因图

停止条件：

- 若参考位姿使最低召回提升超过 0.10，阶段 1 为强制前置。
- 若第三方深度使最低召回提升超过 0.10，阶段 2 为强制前置。
- 若替换深度后边界边仍下降不足 30%，优先检查阶段 3 的融合策略。

### 阶段 1：深度约束的局部位姿细化

实现步骤：

1. 从 MVS 邻接图选择重叠充分的相机对。
2. 把可信参考深度反投影到世界坐标。
3. 投影到邻帧并建立点到平面残差。
4. 增加蒙版轮廓双向距离残差。
5. 增加稀疏特征重投影残差，防止深度主导下的漂移。
6. 对遮挡、深度突变和低置信度使用鲁棒核。
7. 固定一个锚定相机和全局尺度，只优化局部 SE(3) 增量。
8. 只有以下条件全部满足才接受：
   - 跨视深度残差 P90 降低；
   - 稀疏重投影 RMS 不恶化超过 5%；
   - 轮廓 IoU 不下降；
   - 单相机增量不超过安全上限。

输出报告：

- 每台相机平移、旋转增量。
- 位姿协方差。
- 接受/拒绝原因。
- 优化前后逐帧深度残差和召回。

### 阶段 2：逐像素选源和多假设深度

在现有 `MvsSourcePlanner`、`DepthPyramidEstimator`、`PatchMatchCUDA` 和
`DepthGeometryConsistency` 基础上分步实现：

1. 保留整帧候选源池，但逐像素根据可见性、基线角、视线夹角、局部纹理和法线选择 3–5 个源。
2. PatchMatch 在每层保留多个候选深度及代价，而不是过早只保留单一最优解。
3. 使用逆深度域粗到细传播，限制小目标远距离深度量化误差。
4. 增加双向重投影检查、遮挡检查和多视深度中值一致性。
5. 对低纹理但轮廓连续的区域使用边缘感知 TGV；深度突变处降低正则化耦合。
6. 插值只处理有测量锚点的小连通域，并写入 `interpolated` 类别。
7. 对轮廓附近分别统计漏深度和跨轮廓错误深度，不能用单一覆盖率掩盖。

首轮不直接更换默认 PatchMatch；先通过设置开关输出 A/B，三数据集通过后再更新环拍默认值。

### 阶段 3：概率化 TSDF 与可见性约束

在现有 `DepthTsdfSurfaceBuilder`、`AdaptiveTsdfOctree` 和 `SparseTgvSolver` 上扩展：

1. 按像素证据类别和不确定度计算权重及截断带。
2. 把位姿协方差投影到当前像素深度方向。
3. 用可见性距离直方图识别稳定表面带、遮挡带和未知区域。
4. 只在证据冲突或弱覆盖区域增加八叉树细分，稳定平坦区域保持粗节点。
5. 对弱覆盖连通域执行局部稀疏 TGV，不再对完整隐式场无差别正则化。
6. 表面正向证据存在时，单个蒙版或自由空间票不能直接切穿表面。
7. 输出每种拒绝原因、每类证据贡献和逐扇区零交叉可提取率。

当前 16 体素缺口容差保留为上限兜底；位姿细化生效后，实际截断带应自动回落。

### 阶段 4：网格与 GUI 收尾

仅在隐式场质量门通过后执行：

1. 小闭环、受轮廓支持的孔洞填充。
2. 非流形、重复面、翻转面和错误内层清理。
3. 曲率感知重网格化。
4. 平坦区强简化，轮廓、脊线和高曲率区保留。
5. 受 TSDF 约束的切向平滑，禁止跨越置信表面带。
6. GUI 报告实际使用的位姿版本、深度证据分布、融合帧、最大角度缺口和动态截断带范围。
7. GUI 模型任务记录核心配置指纹，CLI 可用同一指纹完整复现。

## 7. 验收门

### 7.1 Hyb2

第一阶段目标：

- 聚合投影召回 ≥ 0.90。
- 中位帧召回 ≥ 0.90。
- P10 帧召回 ≥ 0.82。
- 最低帧召回 ≥ 0.75。
- 第 9、10 帧召回均 ≥ 0.75。
- 跨视深度残差 P90 ≤ 6 个目标体素。
- 边界边相对当前 4,472 再减少至少 70%。
- 不存在覆盖目标投影面积 1% 以上的贯穿孔洞。

最终对齐目标：

- 与 Metashape 参考表面的稳健双向距离 P90 ≤ 目标包围盒对角线的 0.5%。
- 对齐后法线一致性中位数 ≥ 0.90。
- PlaScan 独有且投影面积超过目标面积 0.5% 的孔洞数量为 0。
- 固定七视角 contact sheet 不再出现 Metashape 不存在的大面积空洞。
- 表面粗糙度不能通过过度平滑换取，局部脊线和陨坑边缘必须保留。

### 7.2 Dino 非回归

- 尖刺、耳部和底座不发生粘连。
- 面数不高于当前已接受基线的 110%。
- 边界边、最低帧召回和参考距离 P90 不恶化超过 5%。

### 7.3 Temple 非回归

- 柱间开口保持连通。
- 柱体不出现新的贯穿缺口或错误桥接。
- 边缘 P90、IoU、SSIM 和模型逐视角召回不得低于当前基线。
