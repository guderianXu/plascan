# 深度图直接建模质量完整优化计划

> 状态：持续实施；Task 34、35、40 和 46 已完成阶段验收
> 日期：2026-07-26
> 适用范围：深度图 → 跨视图一致性 → TSDF/TGV → 零等值面 → 网格清理、简化和纹理
> 主要数据集：Dino、Temple
> 主构建目录：`E:\code\plascan\build\windows-vcpkg-cuda-release`

## 1. 目标

在不引入“先生成密集点云”作为强制中间步骤的前提下，提高 PlaScan
从多视图深度图直接生成三维模型的完整性、平滑度和网格效率：

1. 减少柱子、耳朵、薄片、凹槽和轮廓附近的错误空洞。
2. 消除孤立碎片、悬浮三角形、毛边和跨前后表面的错误桥接。
3. 平滑区域使用更少、更规则的三角形，细节和真实锐边得到保留。
4. 让几何、纹理和 GUI 显示问题可以分别测量，不再用纹理观感替代几何验收。
5. 所有默认值必须同时通过 Dino 和 Temple，单数据集特调不能进入默认路径。
6. GUI 保持异步、可取消、有阶段进度；不得因质量优化重新阻塞主线程。

## 2. 非目标与约束

- 不把密集点云设为默认建模前置条件。
- 不用无证据的大范围孔洞填充制造封闭外壳。
- 不用全局强平滑掩盖深度错误。
- 不把“面数更少”单独视为质量提升。
- 不修改或删除用户深度图、项目文件和既有模型产物。
- 不使用 WSL，不创建额外 Python 环境。
- 只使用仓库根目录 `.venv` 和指定 Windows 主构建目录。
- 每个实验必须有独立输出目录，不覆盖当前基线。
- 未经用户明确要求，不提交或推送 GitHub。

## 3. 当前已确认事实

### 3.1 当前有效主线

高细节轨道模型当前启用：

- 可靠帧质量加权和异常帧剔除。
- 深度有效边界的几何验证恢复。
- 保守的轮廓带零交叉恢复，`maximumContourBandAbsoluteTsdf=0.45`。
- 可见性距离直方图。
- 2:1 平衡自适应八叉树。
- 窄带稀疏 TGV。
- 零交叉单元连续表面片恢复，最少 3 个单元、2 个已有表面锚点。
- 保拓扑 QEM、证据约束孔洞修补、三角形质量优化和最终表面去噪。

### 3.3 已拒绝方案

以下方案不得在没有新证据时重新启用：

- 轮廓 TSDF 固定阈值从 0.45 提高到 0.55。
- 边界几何确认从 4 降到 3。
- 几何零交叉单元投票从 2 降到 1。
- 恢复全部被质量门剔除的深度帧。
- 全射线正负号可见性场。
- 仅按 TSDF 角点连接的候选级表面片聚类。
- 无可见性证据的大孔洞填充。
- 单票表面片端点强制限制到 `|TSDF| <= 0.25`。
- 依赖额外拉普拉斯平滑或更高面数解决空洞。

## 4. 验收体系

### 4.1 三层质量门

#### A. 单次改动回滚门

任一场景满足以下条件时，候选方案必须回滚或保持默认关闭：

- 非流形边数量增加。
- 主组件比例下降超过 0.5%。
- 连通组件数增加。
- 边界边增加超过 2%。
- 高长宽比面比例增加超过 2%（相对值）。
- 相邻面法线中位角增加超过 1°。
- Dino Chamfer-L1 增加超过 2.5%。
- 可视化出现新桥接、轮廓塌缩或真实开口被封死。

允许的权衡：

- 边界边至少下降 5%，且组件数不增加时，可接受不超过 2.5% 的 Chamfer
  增量，但必须通过同坐标可视化检查。
- Chamfer 明显改善不能抵消组件分裂或边界显著增加。

#### B. 阶段目标门

第一阶段目标：

| 指标 | Dino 目标 | Temple 目标 |
|---|---:|---:|
| 边界边 | ≤ 20,000 | ≤ 3,500 |
| 连通组件 | ≤ 5 | 1 |
| 高长宽比面 | ≤ 9% | ≤ 5% |
| 法线中位角 | ≤ 26° | ≤ 15° |
| Dino Chamfer-L1 | ≤ 0.00088 | 建立后不得退化 |

第二阶段目标：

| 指标 | Dino 目标 | Temple 目标 |
|---|---:|---:|
| 面数 | 90,000–130,000 | 45,000–65,000 |
| 边界边 | ≤ 10,000 | ≤ 1,500 |
| 连通组件 | ≤ 3 | 1 |
| 高长宽比面 | ≤ 5% | ≤ 3% |
| 法线中位角 | ≤ 20° | ≤ 12° |
| Dino Chamfer-L1 | ≤ 0.00084 | 不低于自身基线 |

#### C. 严格发布门

- Dino 边界边 ≤ 2,500，Temple 边界边 ≤ 500。
- 非流形边为 0。
- 最大组件面占比 ≥ 99.5%。
- 高长宽比面 ≤ 2%。
- 极端长宽比面 ≤ 0.5%。
- Dino 面数不超过 MetaShape 参考的 1.6 倍。
- Dino Chamfer-L1 ≤ 0.00078。
- 预定义近景截图中不得出现明显悬浮片、错误桥接和柱状结构断裂。
- GUI 全流程完成、取消、失败恢复和项目重开均通过。

严格发布门是最终方向，不要求单次改动一次达到。

### 4.2 固定可视化合同

每个被考虑进入默认值的候选必须生成：

1. 正面、侧面、顶面同坐标 contact sheet。
2. Dino 的耳根、面部凹槽、背部鳍片和底座近景。
3. Temple 的四根柱子、柱顶连接、拱口、底座和背面近景。
4. 纯几何灰模、面法线着色、边界边着色三套视图。
5. 与 MetaShape 参考的距离热图。
6. 纹理模型截图只能作为补充，不能替代灰模验收。

可视化脚本必须固定相机、裁剪区域、缩放和随机种子，禁止手动挑选有利视角。

## 5. 总体技术路线

```text
深度与掩膜
  → 边缘双侧深度假设
  → 跨视图投影一致性与可见性
  → 带来源和置信度的表面观测
  → 各向异性 TSDF/TGV
  → 连续零交叉单元片
  → 拓扑明确的等值面提取
  → 证据约束修补
  → 曲率/特征自适应重网格
  → 独立纹理优化
```

优化顺序必须从上游到下游。若边界归因显示空洞来自缺失或冲突深度，不允许先调
QEM、平滑或孔洞填充。

### Task 36：深度边缘双侧假设

**目标：** 改善柱子、耳朵、鳍片等薄结构的边缘定位，不把前景和背景平均。

**主要文件：**

- `src/core/mvs/DepthMapGenerator.cpp`
- `src/core/mvs/DepthGeometryConsistency.h/.cpp`
- `src/core/mvs/DepthFrameQualityGate.h/.cpp`
- `src/core/mvs/tests/test_mvs_pipeline.cpp`

**实施步骤：**

- [ ] 在掩膜和颜色强边缘附近检测深度不连续。
- [ ] 为边缘像素保留前景、背景两个逆深度假设和各自置信度。
- [ ] 亚像素采样时禁止跨越已确认的深度不连续面插值。
- [ ] 用相邻视图投影验证两个假设，而不是仅比较当前像素深度。
- [ ] 将被验证的前景边缘延伸限制在 1–2 像素带内。
- [ ] 记录边缘假设接受、拒绝、冲突和来源视图数量。

**测试：**

- 合成前后平面不得被插值成斜面。
- 一像素细柱在三个视图中应保留连续前景深度。
- 遮挡边不得把背景深度复制到前景。
- 显式掩膜外像素始终无效。

**阶段门：**

- 深度轮廓 P90 误差至少下降 15%。
- 内部有效覆盖不得下降超过 1%。
- 跨视图重投影冲突率不得上升。

### Task 37：跨视图表面假设图

### Task 41：证据约束的孔洞处理

**目标：** 只修复可以由多视图证据证明为缺陷的孔洞。

**实施步骤：**

- [ ] 将边界环分为真实轮廓、遮挡缺口、内部微孔和未知四类。
- [ ] 真实轮廓永不填充。
- [ ] 内部孔洞必须通过多视图投影、深度区间和自由空间检查。
- [ ] 使用局部参数化或最小曲率补片替代简单扇形三角化。
- [ ] 补片生成后执行法线、长宽比和自相交检查。
- [ ] 每个补片独立回滚，不因一个失败补片放弃其他安全补片。

**阶段门：**

- 被填孔洞的 100% 具有记录的可见性证据。
- Temple 拱口和柱间开口保持开放。
- 新增补片高长宽比面不超过 2%。

### Task 42：曲率和特征自适应重网格

- [ ] 高曲率、轮廓和薄结构设置保护环。
- [ ] 边折叠前后检查局部法线翻转、自交和拓扑变化。
- [ ] 先改善三角形分布，再执行最后一次受限减面。
