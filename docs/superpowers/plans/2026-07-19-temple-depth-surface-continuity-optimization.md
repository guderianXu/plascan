# Temple 深度表面连续性与纹理质量优化计划

**目标：** 在继续使用“深度图直接生成 TSDF 三维模型”的前提下，解决 Temple 细柱和横梁的局部缺面、
开放毛边及顶点色错位。优先恢复有跨视证据但未形成网格的真实表面，不使用密集点云中间步骤，不通过
全局膨胀、无条件插值或大孔封口伪造几何。

**执行环境：** Windows 原生 PowerShell；只使用
`E:\code\plascan\build\windows-vcpkg-cuda-release`；MVS 测试统一放在
`src/core/mvs/tests`；Python 只使用仓库根目录 `.venv`；不 reset、checkout、clean、回滚、commit 或 push。

---

## 1. 当前基线与剩余根因

最新 Temple Ultra 384 基线：

- coverage：`0.94975`，已达到 `0.90` 门槛；
- silhouette IoU：`0.88763`，距离 `0.90` 还差 `0.01237`；
- edge P90：`12.48 px`，目标为 `3 px`；
- foreground SSIM：`0.61545`，目标为 `0.75`；
- 网格为一个连通分量，无漂浮分量；
- 13 个 accepted 深度帧、3 个 validation-only 深度帧；
- 三源跨视补回 `4193` 个像素。

剩余问题不是统一的一像素边缘偏移：各视角 edge P50 只有 `1–2 px`，但
`templeSR0014` 的 edge P90 达到 `30.41 px`。长尾来自少数局部大缺面。

逐阶段归因表明存在两类不同问题：

1. `templeSR0012/0014/0016` 的缺失区域主要没有达到强几何支持；
2. `templeSR0009` 有 `3128/3962` 个缺失像素已经具有可靠深度，但没有形成 TSDF 表面。

纹理方面，`680460` 个顶点中只有 `347401` 个获得可靠多视图颜色，`325776` 个依赖最佳单视图回退，
因此 SSIM 不能只靠继续补几何解决。

## 2. 验收原则

每项优化必须在同一 MVS workspace 上执行开关 A/B，不允许用两次独立 SfM/MVS 重跑的随机差异替代
对照。优先级依次为：

1. 不生成柱间薄片、门洞封口和漂浮分量；
2. 降低 edge P90 和开放边界；
3. 提高 IoU 与 coverage；
4. 最后优化纹理 SSIM。

几何改动的最低接受条件：

- component count 保持 `1`；
- largest component face ratio 保持 `1.0`；
- floating diagonal ratio 保持 `0`；
- coverage 不得下降超过 `0.002`；
- IoU 不得下降；
- edge P90 至少改善 `0.5 px`，或开放边界减少至少 `5%`；
- 不接受仅增加面数、同时增加开放边界的方案。

在继续使用 `0.90 / 3 px / 0.75` 严格门槛前，应把 Metashape Temple 模型放入同一相机、同一前景掩膜、
同一分辨率的 `model_quality_cli` 中运行一次。若 Metashape 也不能达到某项门槛，应记录参考模型实测值，
区分“算法尚未达到参考质量”和“门槛本身不可达”，但不能为了让 PlaScan 通过而直接放宽门槛。

## 3. 阶段一：把跨视支持从计数升级为可追踪证据

### 3.1 产物扩展

当前 `raw_geometry_support_path` 只有支持数量，无法判断两个相邻像素是否由相同相机集合确认。新增紧凑
证据产物：

- `raw_geometry_source_mask_path`：最多 16 个源视图的 bit mask；
- `raw_inverse_depth_mean_path`：一致候选的逆深度均值；
- `raw_inverse_depth_spread_path`：一致候选的稳健离散度；
- `cross_view_repaired_mask_path`：明确标记补回像素；
- manifest 记录每项产物路径、版本和统计直方图。

若视图超过 bit mask 容量，只记录实际 source plan 的局部编号，不保存全工程帧号位图。

### 3.2 单元测试

在 `src/core/mvs/tests` 增加测试，验证：

- 同一深度簇正确合并 source ID，重复源视图不能重复计数；
- 前景/背景两个逆深度模式不会被平均；
- source mask、均值和离散度写盘后可无损读取；
- 老 workspace 缺少新产物时保持当前保守行为。

## 4. 阶段二：从三源强种子向两源弱支持区域受控生长

### 4.1 适用范围

只处理一致性过滤后为空、但有两个独立源视图形成稳定逆深度簇的像素。不能把所有两源像素直接恢复。

### 4.2 生长约束

两源候选必须同时满足：

- 与一个三源或更多支持的强种子位于同一连通区域；
- source ID 集合与强种子至少共享一个真实源视图；
- 逆深度相对离散度不超过 `1.0%–1.5%`；
- 与强种子的局部法线夹角不超过 `15°–20°`；
- 图像引导边缘代价没有跨越强梯度；
- 到强种子的 geodesic 距离不超过 `3–5` 像素；
- 不接触 support mask 外部，不跨越深度断层；
- 每个连通补回区域有面积上限，超限区域只保留三源核心。

生长使用优先队列按“支持数、逆深度离散度、法线一致性、图像边缘代价”排序，不使用普通形态学膨胀。

### 4.3 参数 A/B

在同一 Temple 深度 workspace 上至少测试：

- geodesic 半径：`3 / 5`；
- 逆深度离散度：`1.0% / 1.5%`；
- 法线阈值：`15° / 20°`；
- 最大补回连通区域：`32 / 64 / 128` 像素。

若 edge P90 没有改善或开放边界增长超过 `3%`，停止扩大生长范围。

## 5. 阶段三：TSDF 从单体素计数升级为局部表面片支持

### 5.1 解决 `templeSR0009` 的可靠深度未成面

保留默认两个实际相机观测规则，但为以下情况增加局部表面片准入：

- 当前样本至少有两个真实 source ID；
- 逆深度离散度低；
- 邻域 `3x3` 或 `5x5` 内存在已通过双相机 TSDF 的核心体素；
- 样本法线与核心表面法线一致；
- 候选只扩展到核心表面的一个体素邻域；
- free-space 证据没有明确否定该表面。

局部表面片支持不能提高深度帧的 accepted/validation-only 等级，也不能形成没有强核心连接的新组件。

### 5.2 统计与诊断

TSDF JSON 增加：

- `surface_patch_recovered_sample_count`；
- `surface_patch_rejected_normal_count`；
- `surface_patch_rejected_source_overlap_count`；
- `surface_patch_rejected_free_space_count`；
- `surface_patch_created_component_count`；
- 补回前后 boundary edge 数和弱支持面数。

质量报告继续使用 `missing_stage.png`，并新增“可靠深度被 TSDF 拒绝”与“表面片补回成功”两种颜色。

### 5.3 回退条件

出现以下任一情况立即关闭该实验：

- 新增第二个大连通分量；
- 门洞或柱间出现连通薄片；
- boundary edge 增长超过 `3%`；
- IoU 下降超过 `0.001`；
- `templeSR0014` edge P90 继续上升。

## 6. 阶段四：边缘长尾专项优化

对四个验收视角分别输出：

- reference edge；
- rendered edge；
- 双向距离图；
- P90 以上像素掩膜；
- 对应的深度支持数、source ID、逆深度离散度和 TSDF 拒绝原因。

首先处理 `templeSR0014` 的 `30.41 px` 长尾区域。只有确认缺口属于同一真实柱面时，才允许阶段二或阶段三
补回；如果长尾来自前景掩膜边缘偏差，应修正掩膜，不修改深度或网格。

目标是先把每个视角的 edge P90 控制到 `10 px` 以下，再尝试整体 `5 px` 和最终 `3 px`。不使用一次性
大幅放宽支持阈值追逐中位数。

## 7. 阶段五：纹理和 SSIM 单独优化

### 7.1 先校准评估对象

当前质量 CLI 渲染 PLY 顶点色，而最终 OBJ 已有相机投影纹理图集。增加纹理模型渲染或将相同纹理采样
结果转换为质量 CLI 可读输入，分别报告：

- PLY vertex-color SSIM；
- OBJ camera-atlas SSIM；
- 几何公共区域 SSIM；
- 曝光补偿前后 SSIM。

不能用纹理结果掩盖几何缺失；SSIM 只在 reference/render 公共前景上计算。

### 7.2 颜色优化

- 为每个相机估计稳健增益和偏置，统一曝光；
- 每个面优先使用视角、分辨率和遮挡最优的一个主视图；
- 只在几何接缝附近做多带融合，避免整面多视平均导致模糊；
- 对最佳单视图回退顶点记录来源和置信度；
- 禁止颜色传播跨越法线断层或真实开口。

纹理阶段目标：先使 camera-atlas SSIM 超过当前 `0.61545` 至少 `0.05`，再评估 `0.75` 是否可达。
