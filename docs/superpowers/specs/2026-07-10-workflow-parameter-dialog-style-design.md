# PlaScan 重建参数对话框样式设计

## 目标

建立一套可复用的重建参数对话框样式规范，并以“生成模型”对话框作为首个试点。视觉方向采用已确认的 A 方案：接近 Metashape 的紧凑分组布局，降低灰底、留白和重边框带来的视觉噪声。

本次只改变布局与样式，不修改模型生成参数、默认值、候选数据、启用条件、设置序列化或任务调度流程。

## 第一阶段范围

- 新增通用的参数对话框布局与样式辅助模块。
- 在全局 QSS 中新增只对带指定动态属性的参数对话框生效的局部规则。
- 将 `GenerateModelDialog` 迁移到新规范。
- 保留其他重建窗口现状，待试点验证后分阶段迁移。

## 视觉规范

### 对话框

- 使用适合单列表单的稳定内容宽度，长数据项不能无限扩张窗口。
- 外层留白控制在 12–16 px，分组间距控制在 8–10 px。
- 窗口展开高级参数时只改变必要高度，不改变主要字段宽度。
- 100% 和 150% 缩放下优先完整显示内容；屏幕高度不足时只让参数内容区滚动，操作按钮固定可见。

### 表单

- 标签列使用统一宽度和左对齐，字段列自适应剩余空间。
- 行间距保持紧凑，控件高度稳定，避免每个字段形成独立灰色横条。
- `QLabel`、`QCheckBox` 和只读辅助文字背景透明。
- 长候选名称使用受控的组合框尺寸策略，完整内容仍可通过下拉列表或工具提示查看。

### 分组

- “一般”“区域”“高级参数”使用轻量单线边框，不使用卡片阴影和大圆角。
- 分组标题与边框形成明确层级，但颜色和字重低于窗口标题。
- 不在卡片内部再嵌套卡片。

### 高级参数

- “高级”使用整行分隔式折叠按钮，箭头表示当前状态。
- 折叠时不保留空白占位；展开后参数位于带标题的明确分组内。
- 展开和折叠不改变已填写参数。

### 区域切分

- “分割成区块”作为该组的主开关。
- 未启用时，坐标系统、区块大小、网格原点和边界跳过选项使用低对比禁用态。
- 网格原点属于次要只读信息，视觉权重低于可编辑参数。
- 启用和禁用规则保持现有业务逻辑。

### 状态与操作

- 状态说明使用透明背景、较弱文字色和紧凑行高，不与表单字段竞争。
- 操作按钮显示“确定”“取消”，尺寸一致并居中排列。
- 默认按钮继续由 Qt 的默认按钮状态表达。

## 代码结构

新增 `src/gui/dialogs/WorkflowParameterDialogStyle.h/.cpp`：

- `configureWorkflowParameterDialog(QDialog *)`：为窗口设置作用域动态属性和基础尺寸策略。
- `configureWorkflowDialogLayout(QVBoxLayout *)`：统一根布局边距、间距和稳定内容宽度。
- `configureWorkflowScrollArea(QScrollArea *)`：配置高 DPI 下的内容滚动保护。
- `configureWorkflowForm(QFormLayout *)`：统一标签对齐、字段增长策略、边距与行距。
- `configureWorkflowButtonBox(QDialogButtonBox *)`：统一按钮文案、尺寸与居中布局。
- `configureWorkflowComboBox(QComboBox *)`：限制长内容对尺寸提示的影响。

通用模块只负责表现层配置，不保存参数、不连接业务信号，也不持有对话框生命周期。

`resources/styles/app.qss` 新增以动态属性为作用域的规则，例如：

```css
QDialog[workflowParameterDialog="true"] QLabel,
QDialog[workflowParameterDialog="true"] QCheckBox {
    background: transparent;
}
```

所有新增规则必须包含该作用域，避免改变现有对话框。

`GenerateModelDialog` 继续手写控件和业务连接，但使用通用辅助函数配置布局。高级内容改为明确的高级参数分组；现有成员和参数收集接口尽量保持不变。

## 数据与交互

以下行为保持不变：

- `setSourceCandidates()` 的候选数据和自动深度图入口。
- `applySettings()` 与 `collectSettings()` 的参数键和值。
- 源数据切换、区域切分和高级参数变化时发出的 `settingsChanged`。
- `runRequested`、接受/拒绝对话框及默认按钮启用规则。
- 高级参数折叠前后的设置值。

布局刷新继续在 GUI 线程执行，不引入异步任务或磁盘访问。

## 测试与验证

采用 GTest 先增加失败测试，再实现样式：

- 对话框带有通用样式动态属性。
- 表单标签对齐、字段增长策略和关键间距符合规范。
- 组合框使用受控尺寸策略，长数据项不会扩大窗口尺寸提示。
- 高级参数默认折叠，展开后分组可见且宽度保持稳定。
- 用户手动拉宽窗口后切换高级参数，窗口宽度保持不变。
- 默认折叠状态不出现多余滚动条；高 DPI 高度不足时按钮仍固定可见。
- 区域切分开关继续正确控制依赖控件。
- 按钮文案为“确定”“取消”，按钮盒居中。
- `collectSettings()` 的关键参数在布局改动前后保持一致。

实现后构建相关 GUI 测试和 `plascan.exe`。人工检查高级折叠和展开两种状态，并在 100%、150%、200% DPI 下确认文字不截断、控件不重叠、窗口宽度稳定。

## 非目标

- 不在第一阶段迁移其他重建对话框。
- 不新增、删除或重命名模型生成参数。
- 不改变模型生成工作流和源数据选择策略。
- 不把对话框改为标签页、向导或双栏布局。
- 不复制 Metashape 的图标、代码或专有视觉资源。
