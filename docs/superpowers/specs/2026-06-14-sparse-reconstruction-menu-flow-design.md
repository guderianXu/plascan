# 稀疏重建菜单流程优化设计

日期：2026-06-14

## 背景

当前 `重建 -> 稀疏重建` 菜单里已经包含完整的稀疏处理相关动作，但正式生产流程、高级工具和预览/检查功能混在同一层级里。尤其是原先的“生成初始稀疏点云”容易被理解为空中三角测量后的正式稀疏点云，而实际行为更接近基于已有相机和匹配点的两视三角化预览。

本设计的目标是把菜单语义捋清楚：主流程只引导用户生成正式 SfM/BA 稀疏云；高级工具保留，但不再被误认为生产级空三输出。

## 目标

- 让 `重建 -> 稀疏重建` 菜单清楚表达从影像到正式 SfM/BA 稀疏云的生产流程。
- 将主流程与高级工具分离。
- `空中三角测量...` 只负责生成正式 SfM/BA 稀疏云，不继续运行 MVS、网格、DEM 或 DOM。
- 当特征、重叠对或连接点等上游结果缺失时，让用户选择自动补齐缺失步骤或返回手动处理。
- `稀疏点云后处理...` 只允许正式 SfM/BA 稀疏云及其合法后处理结果作为输入。
- 结果记录、DataTree 标签和下游门禁都要区分正式结果与预览结果。

## 非目标

- 不重新设计密集重建、模型生成、DEM 或 DOM 菜单。
- 不移除已有高级工具，例如观测网络、相机位姿初始化、两视预览云、单独光束法平差。
- 首轮实现不要求做完整向导式流程面板。

## 菜单结构

`重建 -> 稀疏重建` 下应分成两个可见分组。

稀疏重建主流程：

1. 特征点提取
2. 重叠对规划
3. 连接点匹配
4. 空中三角测量...
5. 稀疏点云后处理...

高级工具：

1. 查看匹配
2. 构建观测网络
3. 初始化相机位姿
4. 生成两视预览云
5. 单独光束法平差

第二组名称使用 `高级工具`，不使用“稀疏诊断”等名称。

## 空中三角测量入口

`空中三角测量...` 是正式稀疏重建入口，只运行到稀疏阶段：

1. 检查项目影像数量、相机或内参条件。
2. 检查是否已经存在所需的特征、重叠对和连接点匹配结果。
3. 如果上游结果完整，直接运行 SfM 和光束法平差。
4. 如果上游结果缺失，弹窗列出缺失步骤，并提供两个选择：
   - 自动补齐缺失步骤
   - 返回手动处理
5. 如果用户选择自动补齐，显示简化参数页，只确认核心设置：
   - 特征算法
   - 匹配算法或影像对来源
   - CPU/CUDA 设备
   - 质量等级
   - 输出目录
6. 只运行生成正式稀疏结果所需的步骤。
7. 写入正式 SfM/BA 稀疏云和质量元数据后停止。

该入口不得继续运行深度图、密集点云、网格、DEM 或 DOM。

## 结果记录

`aerial_triangulation_results` 中的稀疏结果记录需要显式区分结果类型。

正式空三稀疏云：

- `result_kind = sfm_sparse_reconstruction`
- `ba_applied = true`
- 包含相机数量、点数、track 长度直方图、两视 track 占比和重投影误差统计。
- 可用于稀疏点云后处理、MVS、DEM 和 DOM。

正式云的后处理结果：

- `result_kind = sparse_postprocess`
- `source_result_kind = sfm_sparse_reconstruction`
- 在质量元数据仍然有效时，可继续作为正式稀疏输入。

两视预览云：

- `result_kind = pairwise_triangulation_preview`
- 只用于展示或检查。
- 不允许作为稀疏点云后处理、MVS、DEM 或 DOM 的生产输入。

单独光束法平差预览：

- 在用户确认前保持 pending 或 preview 状态。
- 只有用户确认写回，并带有正式 SfM/BA 质量元数据的结果，才能成为生产级稀疏记录。

## 质量门禁

正式稀疏结果进入下游生产流程前必须满足：

- 已应用光束法平差。
- 注册相机数量不少于 2。
- 有效三维点数量大于 0。
- 存在 track 质量元数据。
- 两视 track 占比低于生产阈值。

如果质量门禁失败，结果仍可在 UI 中展示，但下游生产流程必须拒绝使用，并显示具体原因。

## DataTree 行为

DataTree 标签应明确区分：

- 正式 SfM 稀疏云
- 后处理稀疏云
- 两视预览云
- 未知或遗留稀疏结果

界面应避免只显示笼统的“稀疏点云”，以免用户把预览结果误认为正式空三输出。

## 稀疏点云后处理

`稀疏点云后处理...` 只列出正式 SfM/BA 稀疏云和合法后处理结果。

它不列出两视预览云。如果用户通过旧记录或直接选择路径等方式传入预览云，后处理入口应拒绝，并说明该输入不是正式 SfM/BA 稀疏云。

## 错误处理

上游数据缺失：

- 列出缺少的类别，例如特征、重叠对或连接点匹配。
- 尽量报告缺少多少影像或多少影像对。
- 提供自动补齐或返回手动处理。

质量门禁失败：

- 显示注册相机数量、点数、两视 track 占比和 BA 是否应用。
- 说明结果可以检查，但不能作为生产输入。

误用预览结果：

- 说明所选结果是两视预览云，不能作为正式稀疏重建结果。

## 测试计划

需要补充或更新以下测试：

- 菜单结构测试：主流程与 `高级工具` 分组、动作文案正确。
- 空中三角测量入口测试：缺上游结果时弹窗路径正确；自动补齐参数页能生成运行配置。
- 结果记录测试：正式 SfM/BA 结果带生产级稀疏元数据。
- 预览记录测试：两视预览云永远不能通过 `isProductionSparseResult`。
- 后处理输入测试：只接受正式 SfM/BA 稀疏云和合法后处理结果。
- 下游门禁测试：MVS/DEM 只使用 production sparse result。

## 实现备注

- 正式空三阶段优先复用现有 `SFMService` 能力，但通过稀疏专用的 `空中三角测量...` 入口暴露，并在 SfM/BA 后停止。
- 高级工具继续连接现有 dialog 和 service，但移动到 `高级工具` 分组下。
- 保持项目元数据兼容：遗留的 `operation=triangulation` 记录按两视预览云分类。
- 所有用户可见 UI 文案使用中文。
