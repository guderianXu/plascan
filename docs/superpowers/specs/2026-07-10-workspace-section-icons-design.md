# PlaScan 工作区分类图标设计

## 目标

为 `DataTreeWidget` 的一级分类节点增加可辨识的语义图标，使用户在扫描工作区时能够快速区分照片、连接点、深度成果、模型和测绘成果。视觉方向采用已确认的 B 方案：低饱和分类配色；3D 模型、DEM 和正射影像采用 B1 成果语义图标。

本次改动只调整一级分类节点图标，不改变工作区节点的显示条件、计数规则、展开状态、选择行为或资源加载流程。

## 视觉规范

- 图标以 18 px 为主要显示尺寸，并提供多尺寸绘制结果以适配高 DPI 显示。
- 轮廓应在 16–20 px 范围内仍然清晰，不使用文字、细密纹理或过多装饰。
- 颜色保持低饱和度，选中、高亮和禁用状态继续由 Qt 视图样式负责。
- 图标不得依赖操作系统主题，避免不同 Windows 环境出现形状或颜色差异。

分类映射如下：

| 工作区分类 | 图形语义 | 主色方向 |
| --- | --- | --- |
| 照片 | 文件夹 | 低饱和金色 |
| 观测网络 | 相连节点 | 蓝色 |
| 连接点 | 四点阵列 | 灰蓝色 |
| 深度图 | 层叠栅格 | 青绿色 |
| 稠密点云 | 点簇 | 灰蓝色 |
| 3D模型 | 分面多面体 | 中性灰色 |
| DEM | 地形等高线 | 低饱和绿色 |
| 正射影像 | 正射拼接影像块 | 蓝绿色 |
| 参考数据 | 定位/参考标记 | 低饱和紫灰色 |
| 报告 | 文档 | 棕灰色 |

## 代码结构

新增 `WorkspaceSectionIcons.h/.cpp`，放在 `src/gui/widgets/`：

- 定义工作区分类枚举，避免通过中文标题字符串猜测图标类型。
- 暴露单一图标工厂函数，根据分类返回 `QIcon`。
- 使用 `QPainter` 和 `QPainterPath` 绘制各分类图标，并向同一个 `QIcon` 添加 16–64 px 的多个 `QPixmap`，覆盖常见高 DPI 缩放。
- 未知分类返回稳定的通用资源图标，不能返回空图标。

`DataTreeWidget` 创建一级分类时显式传入分类枚举并设置图标。子资源行保持现有显示方式，本次不新增子项图标，避免树视图过于拥挤。

## 数据与交互

图标生成是纯 GUI 操作，不访问磁盘、不读取项目数据，也不引入异步任务。项目元数据仍由现有 `populateFromMeta()` 决定哪些分类节点出现；图标工厂只消费分类枚举。

刷新项目、切换项目和恢复展开状态时，图标随节点同步重建。图标不参与节点身份判断，因此不会影响现有分类名称、右键菜单或资源激活逻辑。

## 测试与验证

采用 GTest 先增加失败测试，再实现图标：

- 每个工作区分类和通用回退类型都返回非空 `QIcon`。
- 图标能在 16、18、20、24、32、36、48、64 px 渲染出非透明像素。
- 关键分类的图标缓存键不同，防止所有分类误用同一图标。
- `DataTreeWidget` 生成的一级节点图标像素签名与标题对应的分类工厂图标一致。

实现后编译 `test_gui_project_utils` 和 `plascan.exe`，运行工作区相关 GTest。最后启动 GUI，人工检查常用 DPI 下图标尺寸、对齐和选中状态是否正常。

## 非目标

- 不修改工作区分类的显示/隐藏和计数规则。
- 不为每个照片或生成文件添加独立文件类型图标。
- 不调整树视图字体、行高、缩进、右键菜单或拖放行为。
- 不复制 Metashape 的原始图标资源；仅参考其语义层级，自行绘制 PlaScan 图标。
